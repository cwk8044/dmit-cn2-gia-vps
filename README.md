## CN2 GIA、9929、CMIN2、普通 BGP，差在晚 8 点以后

跨境线路的质量排序大致是 **CN2 GIA > AS9929 > 4837 > 普通 BGP**，这个顺序在晚高峰最能看出区别。

普通 BGP 线路走共享带宽，晚上 8 点到 11 点这段，延迟从平时的 150ms 涨到 300ms 以上、顺带丢包，是常见情况。CN2 GIA 是电信的精品骨干网，三网回程都走这条，同一时段延迟波动小得多。这就是为什么两台配置一样的机器，用起来的体感能差一倍。

归属上，CN2 GIA 属电信，AS9929（CUII）属联通，CMIN2 是移动侧的精品线路。有些商家会借联通的 9929 通道回国，让电信、联通、移动用户都走这一条，电信用户能用，峰值速度未必比纯 CN2 GIA 更猛。

DMIT 的产品线就是按这套逻辑切的：Pro 系列走 CN2 GIA，EB（Eyeball）系列走 CMIN2，机房分洛杉矶、香港、东京三地。所以挑套餐其实是在挑两件事——回程走哪条线，机房离你的访客多远。

## 香港、东京、洛杉矶怎么选

选机房等于选你的访客在哪，价格和延迟从来不是同向的。

**香港**：国内访问延迟的常见区间是 30–60ms，也有说法称最好情况能到 20ms，那个数字更接近营销口径，按 30–60ms 规划比较稳。适合访客九成在国内、又不想备案的站，后台操作、数据库交互这类对延迟敏感的场景，50ms 和 180ms 是两种手感。代价是贵，香港 EB 入门 $39.9/月，Pro 起步更高。

**洛杉矶**：国内延迟 150–200ms，比香港慢三到四倍，但带宽和流量给得大方，同价位能拿到 3TB 到 10TB 月流量。访客一半在国内一半在欧美，或者跑爬虫、Bot、跨境业务后台这类不需要即时响应的活，洛杉矶最划算。国内访问优先走 Pro 的 CN2 GIA，业务量大、更在意流量单价的走 EB 的 CMIN2。

**东京**：位置上介于香港和洛杉矶之间，对日本、韩国、东南亚的访客最友好。这里有个容易忽略的细节——东京 T1 和东京 Pro 是两条完全不同的线，T1 走的是大陆普通线路，Pro 才走 CN2 GIA。T1.MINI 月付 $12.90 看着便宜，如果你买它是为了国内访问快，方向就错了；它的价值在于日本本地和亚太方向的访问质量。

## FAQ

**1核1G 够不够用？**

建站、跑轻量服务、科学上网，1 核 1G 足够。真正影响体验的是回程线路，配置排在后面。DMIT 的入门档直接给到 1核2G，跑 WordPress、小型 API、后台脚本都有余量。需要跑数据库、Docker 多容器，再往上选 2核4G 那档。

**要不要为原生 IP 多付钱？**

只在两种情况下成立：解锁特定地区的流媒体，或者做 TikTok、跨境电商这类对 IP 纯净度要求高的运营。英国原生 IP 访问 BBC iPlayer 直接通、同地区的数据中心 IP 提示地区限制，这是实测层面的差别。日常建站、跑自己的服务，普通 IP 够用。如果你买 DMIT 的主要目的就是解锁流媒体，付款前先确认目标机房那一档的 IP 类型，别默认所有档位都是原生 IP。

**先月付还是直接年付？**

按上面的算术，只有 LAX.Pro.TINY 这类小档的年付有明显折扣（省 $31），东京 T1、东京 Pro 的年付等于没有优惠。第一次用，先月付。

**晚高峰到底稳不稳，买之前怎么判断？**

找商家提供的测试 IP，在 20:00–23:00 之间做 ping 和路由追踪，看两个东西：延迟曲线的抖动幅度，以及回程经过的骨干属于哪家运营商（CN2、9929、4837 能看出区别）。只看白天的平均延迟没有意义，差距全在晚高峰那几个小时里。

**买了不合适能退吗？**

DMIT 的退款条款在本文可核实的公开资料里没有明确信息，下单前自己到结算页和服务条款里确认一遍。这也是建议先买最小档月付的原因——试错成本压在一个月的费用上，比赌年付安全。
